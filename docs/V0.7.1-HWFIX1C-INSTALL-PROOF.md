## HWFIX1c purpose

HWFIX1c changes only the mutable `modules/vpn/hy2-tproxy.sh` error reporting so the Hysteria runtime emits safe categorical startup errors directly at the failure point:

- `HY2_CONFIG_INVALID`
- `HY2_START_FAILED`
- `HY2_CONNECT_TIMEOUT`

The existing reconnect cooldown remains responsible for `HY2_RECONNECT_COOLDOWN=N`.

No URI, auth token, obfs password, or raw protected subscription secret is emitted through these categories.
