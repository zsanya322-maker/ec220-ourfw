# EC220-OURFW v0.4 — CI build repo

Минимальный набор для реальной сборки кастомной прошивки **TP-Link EC220-G5 v2** (MT7620A, 8 MB SPI NOR) на базе Padavan-NG. Это исходники + CI; готовый `.bin` собирается в облаке.

v0.4 = v0.3 + все исправления по внешнему аудиту (regression-тест `tests/audit-regressions.py` фиксирует каждое из них).

## Как собрать

1. Открыть вкладку **Actions** → workflow **Build EC220 OURFW** → **Run workflow** (branch `main`).
2. Ждать окончания (примерно 1–2 часа).
3. Скачать артефакт **EC220-G5-v2-OURFW-v0.4**, внутри:

   - `TL_EC220_G5-V2_OURFW-v0.4-<commit>.bin` — web-образ для штатного обновления;
   - `tp_recovery.bin` — для первой заливки через TFTP recovery (128 KiB нулей + web-образ);
   - `BUILD-REPORT.txt`, `SHA256SUMS.txt`, `build.log`.

## Что делает CI

1. Статические проверки + mock-интеграция + аудит-regressions (без железа).
2. Клонирует **точный** commit Padavan `0e6caa2749a8814345c8a0d496a2fde2e6746a7d` (`hadzhioglu/padavan-ng`) — тот же, что в проверенном рабочем образе EC220.
3. Скачивает toolchain и сверяет его **SHA256 + размер** с пином в `variables`.
4. Накатывает OURFW-интеграцию (патчер идемпотентный, fail-closed) и собирает чистую сборку.
5. Проверяет образ по точному имени `TL_EC220_G5-V2_3.4.3.9L-102-<commit>.bin`, размер против раздела Firmware `0x780000` (минус 64 KiB запас) и генерирует recovery-образ с побайтовой проверкой.

## Прошивка

Первая установка — только `tp_recovery.bin` через TFTP recovery роутера (ПК `192.168.0.66`, Reset + питание). Разметка flash не меняется. Stock Дом.ру ZIP держите отдельно как аварийный откат.

**Не прошивайте `.bin`, пока не сверили SHA256 из BUILD-REPORT.**
